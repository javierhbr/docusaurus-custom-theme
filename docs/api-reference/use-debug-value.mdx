# useDebugValue

`useDebugValue` exposes readable labels for custom Hooks inside React DevTools.

## Reference

```tsx
useDebugValue(statusLabel);
```

## Guidance

Only add debug labels to custom Hooks that are reused or hard to inspect. Keep labels short and derived lazily when computation is expensive.
