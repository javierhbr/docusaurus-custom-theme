# useDeferredValue

`useDeferredValue` lets you defer a derived value so the UI can keep responding to urgent interactions.

## Reference

```tsx
const deferredQuery = useDeferredValue(query);
```

## Guidance

Use it for heavy filtered lists, search results, and large previews where input responsiveness matters more than immediate secondary rendering.
