Documentation publishing checklist

Use this checklist before publishing a documentation update.

Build the site

  • Run npm run typecheck to check TypeScript.
  • Run npm run build and resolve broken links reported by Docusaurus.

Check the reading experience

  • Open the changed pages on desktop and mobile.
  • Verify navigation, headings, code blocks, and light and dark themes.
  • Check the original HTML document and its searchable reading page.

Verify discovery and export

  • Search for a phrase from the updated content in the production preview.
  • Use Copy page to verify the Markdown export contains the current page.
  • Confirm the HTML Library links to the published documents.
